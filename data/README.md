# Data

The released LIBERO LeRobot 3.0 snapshot is stored under `data/lerobot_v30/`. Generated T5 caches belong under `data/text_embeds_cache/libero/`. Both are ignored by Git except for directory placeholders.

See `manifests/assets.json` and the root README files for the repository revision, download command, expected layout, and integrity procedure. Do not mix LeRobot 2.1 and 3.0 paths in one Hydra data config.
